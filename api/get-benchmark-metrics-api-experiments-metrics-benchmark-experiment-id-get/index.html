Get Benchmark Metrics

GET 
/api/experiments/metrics/benchmark/:experiment_id

Get benchmark metrics for a given experiment.

Args:​

experiment_id: The unique identifier of the experiment.

Returns:​

List[BenchmarkPerformanceResponseModel]: Metrics over time for the benchmark.

Raises:​

HTTPException: If the benchmark data is not found or a database error occurs.

Request​

Responses​

  • 200
  • 422

Successful Response
