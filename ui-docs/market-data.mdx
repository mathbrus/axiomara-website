The Market Data page helps you answer a simple question before strategy work: _is this dataset usable for analysis?_

You can inspect multiple datasets side by side, compare behavior over time, and quickly spot gaps or anomalies.

## Build a comparison view

Select one or more rows in the dataset list to add them to the chart. The chart updates to match your selection, and legend labels make each series identifiable by exchange, pair, and candle interval.

Use `Clear selection` when you want to reset and start a fresh comparison, or refresh the list if new datasets were added.

![Market data workspace with selected dataset chart](/img/ui/market_data.png)

## What to expect

- Only datasets with a successful status are charted.
- If a selected dataset failed, the page surfaces dataset-specific errors.
- Empty states are explicit, so it is clear whether nothing is selected or no chartable data is available.

This page is typically used as a quality gate before launching experiments or feeding data into strategy iteration.
