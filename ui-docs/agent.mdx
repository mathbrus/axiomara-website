The Agent page is where you run and manage LLM-assisted strategy generation.

In practice, most workflows alternate between two views:

1. Start a new run with clear instructions.
2. Review sessions, rerun if needed, and accept outputs worth promoting.

## Start a new strategy run

Use the run form to choose your model, set temperature, and provide instructions.  
For first-time `new_strategy` runs, at least one instruction field is required. For `existing_strategy` (or existing session reruns), user instructions are required.

Validation is strict by design: required fields and out-of-range temperature values are blocked before submission.

![Agent run form for a new strategy](/img/ui/agent_0.png)

## Review and act on sessions

Once runs are created, the sessions table becomes your control center. You can refresh, rerun promising sessions, and accept generated strategy code when it is ready for downstream testing.

Completed sessions can be expanded for run history and metadata. Running sessions are intentionally not expandable until execution finishes.

![Agent sessions list with rerun and accept actions](/img/ui/agent_1.png)

## Expected outcome

Each session row gives you status, run count, timestamps, and optional trial linkage.  
Accept actions return inline success or error feedback so you can continue iteration without leaving the page.
