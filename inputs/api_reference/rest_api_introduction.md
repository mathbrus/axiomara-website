Use the REST API when you want direct HTTP control over requests, responses, and
transport behavior from any language or runtime.

## Base URL and authentication

- Base URL: `http://localhost:8000`
- Auth header: No authentication required.

## Request and response conventions

- Request bodies and responses use JSON.
- Standard HTTP status codes indicate success and failure conditions.
- Endpoint pages include schema details for fields, enums, and validation rules.

If you prefer SDK ergonomics, the Python Client provides a higher-level interface
with matching capabilities for the same core workflows.
